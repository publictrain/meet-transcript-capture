# Meet 字幕保存

Google Meetに表示された字幕を読み取り、時刻付きの文字起こしをChrome内へ保存する小さな拡張機能です。
この拡張機能自身は音声や字幕を外部サービスへ送信せず、ブラウザ内だけで処理します。

## インストール

1. このページ右上の「Code」から「Download ZIP」を押す。
2. ダウンロードしたZIPファイルを展開する。
3. Chromeで `chrome://extensions` を開く。
4. 右上の「デベロッパー モード」をONにする。
5. 「パッケージ化されていない拡張機能を読み込む」を押す。
6. 展開した `meet-transcript-capture-main` フォルダを選ぶ。

Chromeウェブストア経由ではないため、利用するChromeごとにこの操作が必要です。

## 更新

新しい版を使う場合は、GitHubからもう一度ZIPをダウンロードし、既存フォルダの代わりに新しいフォルダを選び直してください。
同じ拡張機能を再読み込みするだけなら、`chrome://extensions` の丸い矢印を押します。

## プライバシー

- Meetの字幕と保存履歴は、インストールしたChromeの拡張機能専用領域だけに保存します。
- この拡張機能自身は、音声、字幕、アカウント情報を外部サーバーへ送信しません。
- 公開ファイルには作成者や利用者の会議履歴を含みません。
- 拡張機能を削除すると、Chrome内に保存した文字起こし履歴も削除されます。

## 使い方

1. Google Meetへ参加する。
2. Meet標準の「字幕」をONにする。
3. 右下の「Meet 字幕保存」で「記録開始」を押す。
4. 会議を終了する。通話終了を検知すると文字起こしがChrome内へ自動保存される。
5. 「履歴」を押して会議を選び、表示された本文を `⌘C` でコピーしてCodexへ貼り、議事録の要約を依頼する。

「記録停止」を押して手動で保存することもできます。タブを閉じて通話終了を検知できなかった場合は、
字幕変更時の仮保存を、次回Meetを開いたときに自動で正式保存します。

最新20件をChrome拡張機能のローカル保存領域に保持します。外部サービスには送信しません。

## 保存した文字起こしを後から開く

1. Google Meetのホーム画面を開く。
2. 右下の「Meet 字幕保存」で「履歴」を押す。
3. 最新20件から会議を選ぶ。
4. 表示された本文は選択済みになるため、`⌘C` でコピーしてCodexへ貼る。

Chromeツールバーのポップアップが開かない場合でも、Meet画面内の「履歴」からアクセスできます。

## 制約

- Meet標準字幕に表示された内容だけを保存します。字幕の誤認識もそのまま残ります。
- 話者名はGoogle Meetの画面変更で取得方法が不安定なため、初期版では保存しません。
- Googleが字幕部分のHTML構造を変更すると、字幕を検出できなくなる可能性があります。
- 「記録開始」を押す前の発言と、Meet標準字幕をONにする前の発言は保存されません。
